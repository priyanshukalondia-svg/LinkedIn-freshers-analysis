# 📊 What Actually Gets Freshers Hired in India?

### Analysis of 5,000 Indian Job Applicants

This project performs an end-to-end Exploratory Data Analysis (EDA) on a dataset of 5,000 fresher job applicants in India. The goal is to identify the factors that influence hiring outcomes and salary offers, including academic performance, internships, certifications, LinkedIn activity, projects, and profile completeness.

---

## 🎯 Project Objective

Fresh graduates often wonder:

* Does a higher CGPA really help?
* Do internships increase hiring chances?
* Are certifications worth pursuing?
* Does LinkedIn activity impact job opportunities?
* Which factors influence salary packages the most?

This analysis answers these questions using real-world hiring data.

---

## 📂 Dataset Overview

The dataset contains information about:

* Demographic details

* Engineering/academic branch
* Internship experience
* Certifications completed
* Projects completed
* LinkedIn connections
* LinkedIn Premium status

# 🔍 Key Findings

### ✅ Internship Experience Matters

Candidates with internship experience generally achieve better hiring outcomes.

### ✅ Projects Improve Employability

A higher number of completed projects correlates with greater hiring success.

### ✅ Profile Completeness Helps

Well-maintained professional profiles are associated with stronger recruitment outcomes.

### ✅ Certifications Add Value

Certifications contribute positively to candidate visibility and progression through hiring stages.

### ✅ CGPA Is Important but Not Everything

Academic performance helps, but practical experience and projects often play a larger role.

### ✅ Networking Has an Impact

LinkedIn activity and professional networking can improve career opportunities.
